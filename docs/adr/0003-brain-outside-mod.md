# ADR-0003: Мозг вне мода, версионированный протокол

- Статус: Принято (2026-10-27)
- Пересмотреть, если: задержка локального WebSocket станет заметной по сравнению с вызовом LLM
  (не ожидается).

## Контекст

LLM может быть облачной (Claude и др.) или локальной (Ollama, llama.cpp). Модели, промпты и память
агента будут меняться часто, а тело — реже. Вызов LLM занимает от сотен миллисекунд до секунд, тик
сервера — 50 мс.

## Решение

- Мозг — отдельный процесс. Тело поднимает WebSocket на `127.0.0.1` с JSON-RPC 2.0 и токеном.
- Протокол версионирован (`hello.protocol`), есть эпохи и номера событий, идемпотентный
  `request_id`.
- Мозг ставит задачи и реагирует на события; тело выполняет навыки детерминированно. LLM не
  вызывается на каждом тике.
- MCP, если нужен, реализуется в мозге как обёртка над этим протоколом.

## Последствия

- Мозг можно переписывать и менять модели без пересборки мода.
- JSON-схемы протокола хранятся в репозитории (`protocol/`) и служат контрактом между частями.
- Тело должно оставаться безопасным без мозга: рефлексы, зоны, отмена задач работают локально.
