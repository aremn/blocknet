# ADR-0017: Уроки GregTech Arena: изолированный переводчик, инстинкты, блокнот

Статус: принято, 2026-11-02. Дополняет [ADR-0016](0016-worker-jobs.md) (бот-работяга) и
[ADR-0006](0006-cheap-brain.md) (дешёвый мозг, долгая память в мозге).

## Контекст

[GregTech Arena](https://github.com/marsik641/gregtech-arena) — автономный игрок на Claude Code
(Opus 5.5, headless `claude -p`), который за ~63 активных часа дошёл в GTCEu до MV. Его автор
считает, что 80% успеха дала память, остальное — обвязка вокруг модели. Мы прочитали весь репозиторий
и разговор с автором и взяли то, что ложится на бота-работягу: у нас модель только переводит реплику
в задания, а задание целиком делает тело.

Замер нашего мозга до изменений (один ход haiku, `claude -p` с прежними флагами, cwd = корень репо):
CLI загружал 37 скиллов, 73 слэш-команды, плагин, который подкладывает `AGENTS.md` из репозитория,
и авто-память разработчика (`memory_paths` указывал на память этого проекта). На однострочный
системный промпт уходило 1821 входной токен, после изоляции — 1019 (−44%).

## Решение

1. **Изолированный переводчик.** `claude -p` получает `--setting-sources local`,
   `--settings brain/model-settings.json` (выключены плагин AGENTS.md и плагин авторинга,
   авто-память, запрещены встроенные инструменты), `--disable-slash-commands`,
   `--no-session-persistence`, пустой `--mcp-config`, рабочую папку вне репозитория
   (`<tmp>/blocknet-model`) и окружение без автообновлений и фонового трафика. Авторизация
   по подписке остаётся (`--bare` не используется). Codex уже был изолирован своими `-c`;
   у обоих бэкендов убраны мёртвые роли планировщика и исполнителя.
2. **Проверка изоляции** `node brain/check-isolation.js`: один крошечный ход, затем отчёт `init`
   самого CLI сверяется с ожиданием (нет инструментов, MCP-серверов, скиллов, команд, памяти,
   лишних плагинов, cwd вне репо). Печатает `ISOLATION PASS` или список утечек. Запускать после
   обновления Claude Code.
3. **Инстинкты** (`brain/instincts.js`). Когда задание провалилось, к промпту объяснения
   добавляется подсказка по шаблону отчёта тела («нужен инструмент», «сумка полна», «нет такого
   предмета»): где искать причину, не готовый ответ. Тот же провал того же задания повторно
   (координаты и числа не важны, окно 30 минут) добавляет строку «повтор не поможет, скажи, что
   должно измениться».
4. **Блокнот** (`brain/notebook.js`, по мотивам памяти Huygens). Модель не пишет файл: только
   задания с жёсткими полями и лимитами. `name` называет указанный блок («это сундук для руды»),
   `note` запоминает постоянное пожелание («не трогай берёзы»), `forget` удаляет. Повтор пожелания
   другими словами обновляет старое (совпадение слов ≥ 0,6), то же имя места переносит его. Карточку
   блокнота собирает скрипт и кладёт в каждый промпт. `store` и `take` принимают имя места вместо
   p#; `move` остаётся на указанных p#. Файл `brain/logs/notebook.<бот>.json`, запись атомарная.
5. **Смерть помнится как ожог.** После `bot.died` полчаса каждый промпт получает строку
   «Last death: причина, где, сколько минут назад», чтобы бот мог ответить и объяснить.
6. **Разговор после хода** (`node brain/seance.js`, «разговор с мёртвыми» арены). Лог сессии
   хранит промпт и сырой ответ каждого перевода и объяснения; seance показывает той же модели её
   ход и ответ и передаёт вопрос разработчика («почему ты понял так?»). Для отладки промптов.

7. **Проверка публичного репо** (`node tools/check-public.mjs`, как `tools/check_public.py` арены):
   отслеживаемые файлы не содержат домашних путей с именем пользователя, почты (кроме noreply) и
   токенов. CI запускает её на каждом пуше; строка-фикстура помечается `public-check: allow`.

## Что не перенесено и почему

- Эпизоды с бюджетом действий, карточка «как кончился прошлый эпизод», рефери с журналом
  производства и судья застоя: это обвязка автономного игрока на десятки часов. Наш бот ничего не
  делает без приказа (ADR-0016).
- Факты со статусами, проверка памяти куратором по журналу вызовов и общий уровень знаний: наш
  переводчик не узнаёт об игре ничего нового, механику знает тело и его GameTests. Если вернётся
  автономный режим, это первый кандидат.
- Прерывание пачки вызовов при опасности: у нас рефлексы тела работают без модели, а провал
  задания уже снимает остаток его приказа.
- Инструменты как у игрока (квестбук, JEI, `observe`): у переводчика нет инструментов. Квестбуки FTB
  уже индексирует `knowledge/Wiki`.
- Честное зрение вместо полного: решение ADR-0012 остаётся (компаньону важнее найти руду).

## Последствия

- Каждый вызов переводчика дешевле на ~800 входных токенов (1821 → 1019 на коротком промпте)
  и не видит файлы разработчика.
- Добавлены 7 тестов в `brain/test/lessons.test.js`; живой прогон haiku с фейковым телом: «это
  сундук для руды» → `name`, «не трогай берёзы» → `note`, «скинь добычу в рудный» → `deposit` по
  координатам места.
