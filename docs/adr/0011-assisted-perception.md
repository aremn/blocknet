# ADR-0011: Вспомогательное восприятие: карта мира и живые мобы

- Статус: Принято (2026-10-28). Заменяет ADR-0002 в части ориентации; лучи остаются. Режим
  `assisted`; по умолчанию теперь `full` ([ADR-0012](0012-full-perception.md)): руда тоже известна.
- Пересмотреть, если: модель начнёт принимать решения хуже из-за избытка данных на карте, или
  понадобится честный режим для соревнований/сравнений.

## Контекст

Живая игра 2026-10-28 показала, что честное восприятие (ADR-0002) мешает больше, чем помогает:

- житель, увиденный 3 секунды назад, «исчезал»: `attack villager` отвечал `none seen`, потому что
  моб в этот тик не попал в луч, а у мобов в сцене не было рефов, к ним нельзя было даже подойти;
- бот не знал, где деревня и пещеры, пока не покрутит головой; каждый `look` давал 12 строк, которые
  модель плохо читает, и она гоняла бота по случайным постройкам;
- за железом бот сразу рыл шахту, хотя в 13 м была пещера.

Живой игрок держит в голове карту, слышит мобов за стеной и помнит, где была деревня. Модели нужна
такая же короткая и устойчивая картина мира, а не снимки лучей.

## Решение

- **Карта мира** (`map/`): тело само читает загруженные чанки вокруг ботов (без загрузки новых) и
  хранит итог в SavedData уровня, общий для всех ботов:
  - структуры из данных сервера (`StructureStart`: деревни, шахты, руины, модовые тоже) — с рефом,
    именем из реестра, рамкой и числом частей;
  - пещеры по реальным блокам (выборка воздуха под поверхностью), склеенные по соседним чанкам, с
    глубиной и входом (подземный воздух, до которого доходит небесный свет);
  - рельеф для сетки: высота поверхности, вода, лава — считается вживую из карт высот.
- **Живые мобы** (`Radar`): все живые сущности в радиусе 48 блоков без проверки видимости, с
  устойчивыми рефами `e1`, `e2`… и текущей позицией; ушедшие помнятся минуту как «last seen».
- Инструмент `map` даёт модели сетку 9×9 клеток по 16 блоков, список мест и мобов с рефами,
  направлением и расстоянием. `goto` и `attack` принимают рефы мест (`v1`, `k1`) и мобов (`e3`).
- **Руда на карту не попадает.** Руду бот по-прежнему находит глазами (лучи, `look`, проходка);
  тест на утечку из ADR-0002 (одинаковые решения с скрытой рудой и без) остаётся.
- Лучи остаются для «что передо мной сейчас»: прицел, удар, сбор, объекты сцены.

## Последствия

- Бот ориентируется и находит цели как игрок с хорошей памятью, а не как камера.
- `goto` к постройке ведёт на землю у её основания, а не к ближайшему блоку (крыше).
- `attack` догоняет цель по живой позиции и честно отвечает `killed` или `failed: lost`.
- `obtain` за рудой сначала идёт в известную пещеру с входом, шахту роет только без пещеры.
- Сканирование ограничено бюджетом: несколько чанков за тик, только уже загруженные чанки.
