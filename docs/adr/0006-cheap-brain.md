# ADR-0006: Дешёвый мозг: LLM как дирижёр, тело считает само

- Статус: Принято (2026-10-27)
- Дополняет: [ADR-0003](0003-brain-outside-mod.md)
- Пересмотреть, если: появится быстрая и дешёвая локальная модель, которой можно отдавать больше
  решений.

## Контекст

Мозг — Claude Haiku через `claude -p` по подписке, без бюджета на API. Каждый вызов занимает секунды
и съедает лимиты. Позже появится голос: распознанная речь требует быстрого ответа. При этом бот
должен понимать себя (инструменты, их износ, еду, место в инвентаре) и реагировать на то, что
случилось посреди долгой задачи.

## Решение

Слои по цене, от бесплатного к дорогому:

0. **Без LLM.** Простые команды (чат, голос, круговое меню) разбираются правилами. Рефлексы тела:
   поесть, уйти из лавы, отбиться, сменить инструмент, присесть на краю. Навыки крупные («накопай 16
   угля»), пока навык идёт, мозг спит.
1. **Состояние с ревизиями.** Тело делит своё состояние на разделы (тело, инвентарь, задача, позже
   окружение), у каждого номер ревизии. Мозг запрашивает только изменившееся с известной ревизии.
   Выводы считает тело («кирка почти сломана, ~12 блоков», «может копать до алмазов», «еды на ~3
   дня»), а не LLM. Формат для LLM — компактный текст без значений по умолчанию.
2. **Память.** Мир помнит тело (что видело, где сундуки и база, свои леса); LLM получает это по
   запросу. Мозг хранит долгую память (предпочтения игрока, договорённости) и библиотеку планов:
   план, который LLM однажды придумала, тело дальше выполняет само.
3. **LLM-дирижёр.** Отдаёт планы с условиями и обработчиками («если инвентарь полон — отнеси в
   сундук»), а не по одному шагу. Неизменный системный промпт и описания инструментов кешируются;
   меняющаяся часть короткая. Тулсы тела отдаются через MCP, встроенные тулсы Claude Code
   отключены. Расход токенов пишется в лог на каждое решение.

События во время задачи делятся на три уровня:

- тело справляется само (рефлекс), в отчёт идёт одна строка;
- запомнить и сообщить при следующем отчёте (износ, находки);
- разбудить мозг с контекстом задачи и события; мозг решает продолжить, бросить или поменять план.

Задачи лежат в стеке: прерванную можно продолжить. Речь игрока (чат или голос) обрабатывается
сразу: сначала правила, потом LLM. Ответы короткие, чтобы их можно было озвучить.

## Последствия

- Тело становится умнее и больше, мозг — тоньше. Логику, которую можно посчитать, пишем в теле и
  проверяем GameTest-ами.
- Протокол ADR-0003 получает ревизии разделов и запрос разницы.
- Голос подключается как ещё один источник текста, без отдельной логики.
