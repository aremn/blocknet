# ADR-0004: Поиск пути — Automatone из PlayerEngine

- Статус: Принято (2026-10-27)
- Пересмотреть, если: после выноса Automatone не проходит базовые GameTest-сценарии в модовом
  рельефе или его поддержка обходится дороже своего A*.

## Контекст

Нужен серверный поиск пути с копанием и постройкой по ходу. Baritone работает на клиенте.
Automatone (Ladysnake) — серверный форк Baritone, но официально для Fabric и старых версий, автор
предупреждает о багах в сильно модовых мирах. PlayerEngine содержит порт Automatone на 1.21.1
(`automaton/`, ~28k строк, LGPL-3.0, имена Mojang), слабо связанный с остальным кодом.

## Решение

- Вынести `automaton/` из PlayerEngine в подпроект `pathing/` под LGPL-3.0.
- Оставить расчёт пути, виды движения, цели, исполнение пути, `CustomGoalProcess` и `FollowProcess`.
- Убрать процессы, которые ищут блоки сканированием чанков (рентген), команды, рыбалку, клиентский
  код.
- Заменить абстракции моба (`LivingEntityInventory`, `LivingEntityInteractionManager`) интерфейсом
  `BotHands` поверх настоящего игрока.

## Последствия

- Наши изменения в `pathing/` публикуются под LGPL-3.0; остальной код мода может иметь свою лицензию.
- Нужны GameTest-сценарии: яма, столб, копание вниз, лава, дверь.
- Запасной вариант — свой простой A* с теми же целями (`Goal*`).
