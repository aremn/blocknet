# ADR-0016: Бот — работяга: задания в теле, модель только переводит

Статус: принято, 2026-10-30. Заменяет пошаговое исполнение из ADR-0010 (планировщик, исполнитель
шагов, критик, библиотека планов), ADR-0014 (скрипты-навыки) и инструментальный набор исполнителя
из ADR-0012/0013. ADR-0001…0009, 0011, 0015 и тело остаются.

## Причина

Живые прогоны 2026-10-29/30. Приказ «собери МЭ-сеть»: 8 минут на 9 блоков, 28 реплик; тело
работало 55 с, модели — 470 с. «Расчисти площадку» и «вычисти деревья»: исполнитель истратил
лимит вызовов на `look`/`locate`, ничего не сломал, а шаг-проза с условием `ok` засчитался —
бот дважды сказал «✔». Модель, которая шаг за шагом управляет 45 мелкими инструментами, медленная,
теряет контекст между шагами и не может доказать результат прозаического шага.

## Решение

- Бот делает немного, но надёжно: каждое **задание** — детерминированная программа в теле
  (Java) с одним честным отчётом в конце и GameTest. Нет задания — бот говорит, что не умеет.
- Мозг (Node) — **переводчик**: один вызов модели без инструментов превращает реплику игрока в
  одно задание JSON `{"job", аргументы, "reply"}`; мозг запускает его, ждёт отчёт тела и говорит
  одну строку (начало и конец). Простые приказы (стоп, иди сюда, за мной) — правилами без модели.
- Задания первого этапа: `get` (добыть/принести N предметов, при необходимости отдать игроку),
  `smelt` (переплавить руду из инвентаря), `store` (сложить добычу в указанный сундук, перенести
  сундук в сундук), `come`/`follow`/`stop`, `give`/`drop`, `clear` (расчистить квадрат вокруг
  игрока до высоты его пола: только природные блоки по тегам, постройки не трогаются).
- Задания по очереди: новый приказ во время работы встаёт в очередь, «стоп» отменяет всё.
  «Что делаешь?» отвечается из состояния задания.
- Бот не делает ничего по своей инициативе (дела IdleLife убраны); компаньон (взгляд, ходьба
  рядом, приветствие) остаётся.

## Что вырезано

Из мозга: планировщик (wiki/веб-поиск), исполнитель шагов и MCP-сервер, критик и библиотека
планов, скрипты-навыки, классификатор чата, отдельный «быстрый рот», бенч ролей. Из тела: задачи
IdleLife (`Chores`). Мостовые инструменты тела остаются (команды `/blocknet` и GameTests их
используют), мозг просто вызывает только задания. Состояние до вырезания — тег `before-worker`.

## Следующие этапы

Одно задание за раз, каждое с GameTest: поддержание запасов по порогам, сбор комплекта (Незер),
рецепты машин модов из `RecipeManager`, автокрафт сети. Сначала надёжность, потом количество.
