# ADR-0008: Мост по TCP с JSON lines

- Статус: Принято (2026-10-27)
- Заменяет: транспорт WebSocket в [ADR-0003](0003-brain-outside-mod.md)
- Пересмотреть, если: мозгу понадобится подключаться с другой машины.

## Контекст

Мост работает только на localhost. Для WebSocket нужна дополнительная библиотека, хотя обеим
сторонам достаточно передавать JSON-RPC. MCP stdio уже использует один JSON-объект на строку.

## Решение

- Обычный TCP на `127.0.0.1`, JSON-RPC 2.0, UTF-8, один объект на строку; `java.net` и штатный Gson.
- Порт (по умолчанию 25599) и случайный токен — в `config/blocknet_ai-bridge.json`.
- Сначала `hello {protocol:1, token}`, затем `tool.call {bot, tool, args}`. Список инструментов
  приходит в `hello`. Задача сразу возвращает `task_id`, итог — событием `task.finished`.
- Сетевые потоки только читают сообщения; все вызовы выполняются через `server.execute`.
- MCP остаётся обёрткой в отдельном Node-процессе; отсутствие мозга не меняет локальную игру.

## Последствия

Нет новой зависимости и другого способа кадрирования для MCP. Мост не доступен извне машины.
Первая версия реализует только методы и события из раздела 5 архитектуры; эпохи, повтор запросов
и прочие расширения ADR-0003 пока не реализованы. После обрыва действия автоматически не повторяются.
