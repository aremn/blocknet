# ADR-0002: Честное восприятие

- Статус: Принято (2026-10-27); в части ориентации заменено [ADR-0011](0011-assisted-perception.md)
  (карта структур и пещер, живые мобы). Руда по-прежнему только глазами.
- Пересмотреть, если: стоимость лучей на серверном потоке не укладывается в бюджет даже с
  разреженной сеткой; тогда рассмотреть снимки чанков и обработку вне потока.

## Контекст

Сервер знает весь загруженный мир. Если отдать это знание боту, он будет искать руду сквозь стены.
Так делают Baritone, altoclef и PlayerEngine (`BlockScanner` сканирует чанки). Нам нужен напарник,
который ищет как игрок.

## Решение

- Бот видит только лучами из своих глаз (`Level.clip`, `ClipContext.Block.VISUAL`), в пределах поля
  зрения и дальности, с правилом освещённости.
- У каждого факта есть происхождение: `VISIBLE_NOW`, `REMEMBERED`, `API_OBSERVED`, `INFERRED`, и время.
- Индексы по палитрам секций — только ускорение запроса «что из этого видно сейчас». Они не влияют
  на поворот головы, маршрут и выбор целей.
- Слух — отдельный канал с примерным направлением.
- Режим `debug_omniscient` существует только для отладки.

## Последствия

- Бот ищет ресурсы дольше: осматривается, копает ветки, ставит факелы.
- Нужен тест на утечку: два мира с одинаковой поверхностью и разной скрытой рудой должны давать
  одинаковые решения до первого открытия различий.
- Поиск пути (ADR-0004) видит реальную геометрию рядом с ботом — это осознанный компромисс.
