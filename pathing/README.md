# pathing

Server-side pathfinding for Blocknet bots, extracted from [Automatone](https://github.com/Ladysnake/Automatone)
(a server-side fork of [Baritone](https://github.com/cabaletta/baritone)) as ported to Minecraft 1.21.1
in [PlayerEngine](https://github.com/shakey2/PlayerEngine) (branch `1.21.1-arch-persistentdata`, commit `40732ba`).
